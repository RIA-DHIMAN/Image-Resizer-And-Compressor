**Image Resizer & Compressor**
A lightweight, browser-based tool designed to help users quickly resize and compress images without losing quality. Perfect for web developers, content creators, and anyone looking to optimize their web performance.

**Features**
Batch Processing: Upload and process multiple images at once.
Smart Compression: Reduce file size significantly while maintaining visual integrity.
Custom Dimensions: Manually set width and height or maintain aspect ratios.
Format Conversion: Convert between PNG, JPG, and WebP formats.
Privacy First: All processing happens locally in your browser. Your images are never uploaded to a server.
